<context>
## Project Structure

Interview Ninja is a Flask monolith with a 4-tier architecture:

- **Presentation:** Jinja2 templates + vanilla JS + Chart.js
- **Application:** Flask blueprints + REST endpoints
- **AI Inference:** Pluggable analyzer modules (emotion, voice, posture, NLP)
- **Data:** SQLAlchemy ORM + SQLite (dev) / PostgreSQL (prod)

## Database Schema (6 Entities)

```
candidates (1) ──< sessions (1) ──< questions
                     │
                     ├──< responses (1) ──< analysis_results
                     │
                     └──< reports
```

Key constraints:

- `session_id` UNIQUE per candidate (MVP: one-at-a-time)
- `questions.sequence` UNIQUE per session (prevents duplicates)
- `responses` status: "recorded" | "analyzing" | "analyzed" | "failed"
- `sessions` status: "created" | "in_progress" | "completed" | "analyzing" | "analyzed" | "failed"

## Tech Stack (Foundation Layer)

- **Framework:** Flask 3.0+
- **ORM:** SQLAlchemy 2.0+ (compatible SQLite + PostgreSQL)
- **Database:** SQLite dev, PostgreSQL prod
- **Resume Parsing:** PyMuPDF, python-docx, spaCy
- **AI Inference:** DeepFace, MediaPipe, librosa, sentence-transformers
- **Async:** Python ThreadPoolExecutor
- **Media:** ffmpeg-python, WebM/WAV
- **PDF Export:** WeasyPrint
- **Deployment:** Vercel or standalone Flask

## Key Design Decisions (D-01 through D-07)

- **D-02:** Load all AI models as singletons in `app.py` during initialization (no per-request reload)
- **D-03:** CPU-only inference (supports academic hardware ≥8GB RAM)
- **D-04:** SQLite for development; schema compatible with PostgreSQL via SQLAlchemy abstraction
- **D-06:** No authentication in MVP; single-user testing only

    ## Architecture
    
    Interview Ninja follows a 4-tier N-tier architecture:
    
    ```
    ┌─────────────────────────────┐
    │  Presentation Tier (Browser) │  HTML/CSS/JS, Chart.js
    ├─────────────────────────────┤
    │  Application Tier (Flask)    │  REST API, Session Management
    ├─────────────────────────────┤
    │  AI Inference Tier          │  Emotion, Voice, Posture, NLP Analysis
    ├─────────────────────────────┤
    │  Data Tier (SQLAlchemy/DB)  │  SQLite (dev), PostgreSQL (prod)
    └─────────────────────────────┘
    ```
    
    ## Five-Phase Development

    2. **Phase 2: Input Pipeline** (3-5 days) — Resume upload, question generation
    3. **Phase 3: Interview Session** (3-5 days) — Recording, media capture
    4. **Phase 4: AI Analysis** (7-10 days) — All 4 AI modules
