## Server Media Handling (Decisions D-08 to D-10)

- **D-08:** Save each response as WebM: `recordings/{session_id}/q{n}.webm`
- **D-09:** Extract audio post-upload: `recordings/{session_id}/q{n}.wav` (16kHz, PCM)
- **D-10:** Audio extraction async (ThreadPoolExecutor, non-blocking)

## Session Lifecycle

```
Client uploads WebM blob (POST /upload-response)
  ↓
Server saves WebM file
  ↓
Server updates Response row (video_path set)
  ↓
Server submits audio extraction task to ThreadPoolExecutor (async)
  ↓
Client polls /status → returns immediate response (video_path set, analysis pending)
  ↓
[Meanwhile, extraction runs in background]
  ↓
Extraction completes → Response row updated (audio_path set)
  ↓
Client advances to next question
  ↓
(Repeat for all questions)
  ↓
Client submits final question
  ↓
Client clicks "Submit Interview" → POST /complete
  ↓
Server triggers analysis async (ThreadPoolExecutor)
  ↓
Client redirects to analysis_wait screen
  ↓
Client polls GET /status every 2 seconds
  ↓
Analysis completes → status returns "complete"
  ↓
Client redirects to report page
```

## Error Handling & Recovery (D-14 to D-15)

- **D-14:** Upload failure → auto-retry 3 times (1s, 2s, 4s backoff), then show manual retry button
- **D-15:** Browser crash → localStorage tracks session state; on restart, offer resume
  - Session last_activity timestamp on server (< 2 hours = valid)
  - Response table tracks which responses uploaded (video_path != null)
  - Resume skips already-uploaded questions

## Tech Details

- **FFmpeg command (D-09):** `ffmpeg -i {webm} -acodec pcm_s16le -ar 16000 {wav}`
- **Async execution:** ThreadPoolExecutor (Python stdlib, as per PROJECT.md D-02)
- **File organization:** Flat structure under recordings/{session_id}/q{n}.{ext}
- **Status tracking:** Session.status field: "created", "in_progress", "submitted", "analyzing", "analyzed", "failed"

import os
import shutil
import subprocess
from pathlib import Path
from datetime import datetime
import logging

logger = logging.getLogger(__name__)

class MediaHandlingError(Exception):
    """Custom exception for media handling errors"""
    pass

class MediaHandler:
    """Handle media file storage and processing"""

    RECORDINGS_DIR = 'recordings'
    FFMPEG_TIMEOUT = 120  # seconds

    def __init__(self, base_dir: str = RECORDINGS_DIR):
        self.base_dir = base_dir
        os.makedirs(base_dir, exist_ok=True)

    def get_session_dir(self, session_id: int) -> str:
        """Get or create session recording directory"""
        session_dir = os.path.join(self.base_dir, f'session_{session_id}')
        os.makedirs(session_dir, exist_ok=True)
        return session_dir

    def save_media(self, blob: bytes, session_id: int, question_number: int) -> dict:
        """
        Save WebM video blob to disk.

        Args:
            blob: WebM video blob (bytes)
            session_id: Session ID
            question_number: Question number (1-indexed)

        Returns:
            dict with video_path and filename

        Raises:
            MediaHandlingError on failure
        """
        try:
            session_dir = self.get_session_dir(session_id)
            video_filename = f'q{question_number}.webm'
            video_path = os.path.join(session_dir, video_filename)

            # Write blob to file
            with open(video_path, 'wb') as f:
                f.write(blob)

            if not os.path.exists(video_path):
                raise MediaHandlingError(f'Failed to write video file: {video_path}')

            file_size = os.path.getsize(video_path)
            logger.info(f'Saved video: session={session_id}, q{question_number}, size={file_size} bytes')

            return {
                'success': True,
                'video_path': f'recordings/session_{session_id}/{video_filename}',
                'filename': video_filename,
                'size': file_size,
                'timestamp': datetime.utcnow().isoformat()
            }
        except Exception as e:
            logger.error(f'Error saving media: {e}')
            raise MediaHandlingError(f'Failed to save media: {str(e)}')

    def extract_audio(self, session_id: int, question_number: int) -> dict:
        """
        Extract audio from WebM video using FFmpeg.
        Called async from ThreadPoolExecutor.

        Args:
            session_id: Session ID
            question_number: Question number (1-indexed)

        Returns:
            dict with audio_path and extraction metadata

        Raises:
            MediaHandlingError on failure
        """
        try:
            session_dir = self.get_session_dir(session_id)
            video_filename = f'q{question_number}.webm'
            audio_filename = f'q{question_number}.wav'

            video_path = os.path.join(session_dir, video_filename)
            audio_path = os.path.join(session_dir, audio_filename)

            # Check if video exists
            if not os.path.exists(video_path):
                raise MediaHandlingError(f'Source video not found: {video_path}')

            if os.path.exists(audio_path):
                logger.info(f'Audio already extracted: {audio_path}')
                return {
                    'success': True,
                    'audio_path': f'recordings/session_{session_id}/{audio_filename}',
                    'filename': audio_filename,
                    'already_existed': True
                }

            # FFmpeg command: extract audio, PCM 16-bit, 16kHz
            # This matches Google Speech-to-Text specs
            cmd = [
                'ffmpeg',
                '-i', video_path,
                '-acodec', 'pcm_s16le',
                '-ar', '16000',
                '-ac', '1',  # Mono audio (required by STT)
                '-y',  # Overwrite output file
                audio_path
            ]

            logger.info(f'Running FFmpeg: {" ".join(cmd)}')

            result = subprocess.run(
                cmd,
                stdout=subprocess.PIPE,
                stderr=subprocess.PIPE,
                timeout=self.FFMPEG_TIMEOUT
            )

            if result.returncode != 0:
                error_msg = result.stderr.decode('utf-8', errors='ignore')
                raise MediaHandlingError(f'FFmpeg failed: {error_msg}')

            if not os.path.exists(audio_path):
                raise MediaHandlingError(f'Audio extraction failed: output file not created')

            audio_size = os.path.getsize(audio_path)
            logger.info(f'Audio extracted: session={session_id}, q{question_number}, size={audio_size} bytes')

            return {
                'success': True,
                'audio_path': f'recordings/session_{session_id}/{audio_filename}',
                'filename': audio_filename,
                'size': audio_size,
                'timestamp': datetime.utcnow().isoformat()
            }
        except subprocess.TimeoutExpired:
            logger.error(f'FFmpeg timeout for session={session_id}, q{question_number}')
            raise MediaHandlingError(f'Audio extraction timeout')
        except Exception as e:
            logger.error(f'Error extracting audio: {e}')
            raise MediaHandlingError(f'Failed to extract audio: {str(e)}')

    def get_session_files(self, session_id: int) -> dict:
        """
        Get list of media files for a session.

        Returns:
            dict mapping question_number to {video_path, audio_path, status}
        """
        session_dir = self.get_session_dir(session_id)
        files = {}

        # Scan directory for WebM and WAV files
        webm_files = sorted(Path(session_dir).glob('q*.webm'))
        wav_files = sorted(Path(session_dir).glob('q*.wav'))

        for webm_path in webm_files:
            question_num = int(webm_path.stem.lstrip('q'))
            wav_path = session_dir / f'q{question_num}.wav'

            files[question_num] = {
                'video': webm_path.name,
                'video_path': str(webm_path),
                'audio': wav_path.name if wav_path.exists() else None,
                'audio_path': str(wav_path) if wav_path.exists() else None,
                'extraction_complete': wav_path.exists()
            }

        return files

    def cleanup_session(self, session_id: int, delete_after_days: int = 7) -> bool:
        """
        Remove old session recordings (optional cleanup task).

        Args:
            session_id: Session ID
            delete_after_days: Delete if older than N days

        Returns:
            True if deleted, False if kept
        """
        try:
            session_dir = self.get_session_dir(session_id)
            session_created = os.path.getctime(session_dir)
            age_days = (datetime.utcnow().timestamp() - session_created) / 86400

            if age_days > delete_after_days:
                shutil.rmtree(session_dir)
                logger.info(f'Cleaned up session: {session_id} ({age_days:.1f} days old)')
                return True

            return False
        except Exception as e:
            logger.error(f'Error cleaning up session: {e}')
            return False

# Global instance
media_handler = None

def get_media_handler() -> MediaHandler:
    """Get or create global MediaHandler instance"""
    global media_handler
    if media_handler is None:
        media_handler = MediaHandler()
    return media_handler

@session_bp.route('/upload-response', methods=['POST'])
def upload_response():
    """
    Upload WebM video blob for a question response.
    Endpoint: POST /api/v1/session/upload-response

    Expected form data:
    - session_id: int
    - question_id: int
    - video: file blob (WebM)

    Response JSON:
    - 200: {'status': 'ok', 'message': 'Response uploaded', 'response_id': int}
    - 400: {'error': 'Missing fields'}
    - 404: {'error': 'Session not found'}
    - 500: {'error': 'Failed to save media'}
    """
    try:
        # Parse request
        session_id = request.form.get('session_id', type=int)
        question_id = request.form.get('question_id', type=int)
        video_blob = request.files.get('video')

        if not all([session_id, question_id, video_blob]):
            return jsonify({'error': 'Missing required fields: session_id, question_id, video'}), 400

        # Validate session exists and is in progress
        session = Session.query.get(session_id)
        if not session:
            return jsonify({'error': f'Session {session_id} not found'}), 404

        if session.status not in ['created', 'in_progress']:
            return jsonify({'error': f'Session status {session.status} does not allow new responses'}), 400

        # Update session status if first response
        if session.status == 'created':
            session.status = 'in_progress'
            db.session.commit()

        # Save WebM blob using MediaHandler
        media_handler = get_media_handler()
        try:
            media_result = media_handler.save_media(
                blob=video_blob.read(),
                session_id=session_id,
                question_number=question_id  # Assuming question_id is sequence/number
            )
        except MediaHandlingError as e:
            logger.error(f'Media save failed: {e}')
            return jsonify({'error': f'Failed to save media: {str(e)}'}), 500

        # Create or update Response record
        response = Response.query.filter_by(
            session_id=session_id,
            question_id=question_id
        ).first()

        if not response:
            response = Response(
                session_id=session_id,
                question_id=question_id,
                sequence=question_id
            )
            db.session.add(response)

        # Set video path
        response.video_path = media_result['video_path']
        response.uploaded_at = datetime.utcnow()
        db.session.commit()

        # Trigger async audio extraction via ThreadPoolExecutor
        # This runs in background; client doesn't wait

            executor = current_app.config.get('executor')
            if executor:
                executor.submit(

                    question_id=question_id,
                    response_id=response.id

            logger.warning(f'Failed to queue audio extraction: {e}')

            'status': 'ok',

    """
    Get current session status and analysis progress.
    Endpoint: GET /api/v1/session/{session_id}/status

    Response JSON:
    - 200: {
        'status': 'in_progress|submitted|analyzing|analyzed|failed',
        'progress': {'uploaded': 5, 'total': 10},
        'analysis_status': 'pending|running|complete|error',
        'message': 'string'

        session = Session.query.get(session_id)
        if not session:
            return jsonify({'error': f'Session {session_id} not found'}), 404

        # Get response statistics
        total_responses = Response.query.filter_by(session_id=session_id).count()
        uploaded_responses = Response.query.filter_by(session_id=session_id).filter(
            Response.video_path != None
        ).count()
        extraction_complete = Response.query.filter_by(session_id=session_id).filter(
            Response.audio_path != None
        ).count()

        # Determine analysis status
        analysis_status = 'pending'
        if session.status == 'analyzing':
            analysis_status = 'running'
        elif session.status in ['analyzed', 'completed']:
            analysis_status = 'complete'
        elif session.status == 'failed':
            analysis_status = 'error'

        return jsonify({
            'status': session.status,
            'session_id': session_id,
            'progress': {
                'uploaded': uploaded_responses,
                'total': total_responses,
                'extraction_complete': extraction_complete
            },
            'analysis_status': analysis_status,
            'created_at': session.created_at.isoformat() if session.created_at else None,
            'submitted_at': session.submitted_at.isoformat() if session.submitted_at else None
        }), 200

    except Exception as e:
        logger.error(f'Error getting session status: {e}')
        return jsonify({'error': f'Server error: {str(e)}'}), 500

    constructor(sessionId) {
      this.sessionId = sessionId;
      this.pollInterval = 2000; // 2 seconds
      this.maxAttempts = 180; // 6 minutes max
      this.attempts = 0;
      this.pollingActive = true;
    }

    async startPolling() {
      console.log(`Starting analysis polling for session ${this.sessionId}`);

      while (this.pollingActive && this.attempts < this.maxAttempts) {
        this.attempts++;

        try {
          await this.checkStatus();
        } catch (error) {
          console.error("Polling error:", error);
          this.showError(`Polling error: ${error.message}`);
          break;
        }

        // Wait before next poll
        await new Promise((resolve) => setTimeout(resolve, this.pollInterval));
      }

      if (this.attempts >= this.maxAttempts) {
        this.showError(
          "Analysis took too long. Please try again or contact support.",
        );
        this.pollingActive = false;
      }
    }

    async checkStatus() {
      const response = await fetch(`/api/v1/session/${this.sessionId}/status`);
      const data = await response.json();

      if (!response.ok) {
        throw new Error(data.error || "Failed to check status");
      }

      this.updateUI(data);

      // Check if analysis is complete
      if (data.analysis_status === "complete") {
        this.pollingActive = false;
        this.onAnalysisComplete();
      }
    }

    updateUI(data) {
      const { status, progress, analysis_status } = data;

      // Update upload status
      document.getElementById("uploadStatus").textContent =
        progress.uploaded === progress.total
          ? "✓ Complete"
          : `${progress.uploaded}/${progress.total}`;

      // Update extraction status
      const extractionPercent =
        progress.total > 0
          ? Math.round((progress.extraction_complete / progress.total) * 100)
          : 0;
      document.getElementById("extractionStatus").textContent =
        `${progress.extraction_complete}/${progress.total} (${extractionPercent}%)`;

      // Update analysis status
      if (analysis_status === "pending") {
        document.getElementById("analysisStatus").textContent = "Pending...";
      } else if (analysis_status === "running") {
        document.getElementById("analysisStatus").textContent = "⏳ Running...";
      } else if (analysis_status === "complete") {
        document.getElementById("analysisStatus").textContent = "✓ Complete";
      }

      // Update main message
      if (status === "submitted") {
        document.getElementById("mainStatus").textContent =
          "Extracting audio from responses...";
      } else if (status === "analyzing") {
        document.getElementById("mainStatus").textContent =
          "Running AI analysis (emotion, speech, posture, answer quality)...";
      } else if (status === "analyzed") {
        document.getElementById("mainStatus").textContent =
          "Generating your report...";
      }
    }

    onAnalysisComplete() {
      console.log("Analysis complete!");
      document.getElementById("mainStatus").textContent =
        "✓ Analysis Complete!";
      document.getElementById("mainStatus").classList.add("success");

      // Wait 1 second then redirect to report
      setTimeout(() => {
        window.location.href = `/report/${this.sessionId}`;
      }, 1000);
    }

    showError(message) {
      const errorEl = document.getElementById("errorAlert");
      errorEl.textContent = message;
      errorEl.classList.remove("hidden");
      console.error(message);
    }
  }

  document.addEventListener("DOMContentLoaded", () => {
    const urlParams = new URLSearchParams(window.location.search);
    const sessionId = urlParams.get("session_id");

    if (!sessionId) {
      console.error("No session_id provided");
      document.querySelector(".status-message").innerHTML =
        '<p class="alert alert-danger">Invalid session. Please start over.</p>';
      return;
    }

    const poller = new AnalysisPoller(sessionId);
    poller.startPolling().catch((error) => {
      console.error("Fatal polling error:", error);
      poller.showError(`Fatal error: ${error.message}`);
    });
  });
</script>
