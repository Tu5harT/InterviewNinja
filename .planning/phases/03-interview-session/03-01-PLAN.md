## Recording Requirements (FR-03, FR-04, FR-05)

- Accept webcam + microphone inputs via getUserMedia (FR-03)
- Display live preview (FR-03)
- Time limit per question: 90 seconds (FR-04)
- Include visible recording indicator (FR-03)
- Allow manual stop or auto-stop at timer end (FR-04)
- Gracefully handle permission denial (FR-05)
- Save media files to disk (per session/question)
- Extract audio from video for analysis

## Interview Session Flow

```
Start Interview
  ↓
Load Question 1
  ↓
User clicks "Start Recording"
  ↓
Webcam + Mic active (90s timer)
  ↓
User clicks "Stop Recording" OR timer reaches 0
  ↓
Upload WebM blob to server
  ↓
Server saves WebM, extracts WAV via ffmpeg
  ↓
Next question available
  ↓
(Repeat for all questions)
  ↓
Final "Submit Interview"
  ↓
Async analysis triggered
  ↓
Redirect to analysis_wait screen

```

## Tech Stack (Phase 3 Layer)

- **Browser API:** getUserMedia (WebRTC), MediaRecorder
- **Video Codec:** WebM (VP8/Vorbis) — widely supported
- **Audio Processing:** ffmpeg (subprocess call; must be installed)
- **Upload Protocol:** Chunked FormData POST (no WebRTC streaming)
- **Storage:** Filesystem (`recordings/{session_id}/q{n}.webm`, `q{n}.wav`)
- **Async Job Trigger:** ThreadPoolExecutor (from Phase 1 app.py)
- **Frontend State:** JavaScript (vanilla, no frameworks for simplicity)

## Browser Compatibility

- Chrome 90+: Full support
- Firefox 88+: Full support
- Safari 14.1+: getUserMedia supported; WebM may not be natively playable (but can be stored)
- Edge 90+: Full support

    /**
     * Media Capture Abstraction
     * Wraps getUserMedia and MediaRecorder APIs
     */
    
    class MediaCaptureManager {
        constructor(videoElementId = 'webcamPreview') {
            this.videoElement = document.getElementById(videoElementId);
            this.mediaStream = null;
            this.mediaRecorder = null;
            this.recordedChunks = [];
            this.isRecording = false;
        }
        
        /**
         * Request webcam and microphone access
         * Returns: Promise<MediaStream | null>
         */
        async requestMediaAccess() {
            try {
                const constraints = {
                    video: {
                        width: { ideal: 640 },
                        height: { ideal: 480 },
                        facingMode: 'user'
                    },
                    audio: {
                        echoCancellation: true,
                        noiseSuppression: true
                    }
                };
                
                this.mediaStream = await navigator.mediaDevices.getUserMedia(constraints);
                
                // Attach stream to video element
                if (this.videoElement) {
                    this.videoElement.srcObject = this.mediaStream;
                    // Wait for video to start playing
                    await new Promise(resolve => {
                        this.videoElement.onloadedmetadata = () => {
                            this.videoElement.play();
                            resolve();
                        };
                    });
                }
                
                return this.mediaStream;
            } catch (error) {
                console.error('Error accessing media:', error);
                if (error.name === 'NotAllowedError') {
                    throw new Error('Permission denied. Please grant access to webcam and microphone.');
                } else if (error.name === 'NotFoundError') {
                    throw new Error('No webcam or microphone found on this device.');
                } else {
                    throw new Error(`Media access error: ${error.message}`);
                }
            }
        }
        
        /**
         * Start recording
         * Returns: Promise<void>
         */
        async startRecording() {
            if (!this.mediaStream) {
                throw new Error('No media stream available. Call requestMediaAccess first.');
            }
            
            // Clear previous chunks
            this.recordedChunks = [];
            
            try {
                // Create MediaRecorder with WebM codec
                const options = {
                    mimeType: 'video/webm;codecs=vp8,opus',
                    videoBitsPerSecond: 2500000  // 2.5 Mbps
                };
                
                // Fallback if WebM not supported
                if (!MediaRecorder.isTypeSupported(options.mimeType)) {
                    options.mimeType = 'video/webm';
                }
                
                this.mediaRecorder = new MediaRecorder(this.mediaStream, options);
                
                this.mediaRecorder.ondataavailable = (event) => {
                    if (event.data.size > 0) {
                        this.recordedChunks.push(event.data);
                    }
                };
                
                this.mediaRecorder.onerror = (event) => {
                    console.error('MediaRecorder error:', event);
                    throw new Error(`Recording error: ${event.error}`);
                };
                
                this.mediaRecorder.start();
                this.isRecording = true;
            } catch (error) {
                console.error('Error starting recording:', error);
                throw error;
            }
        }
        
        /**
         * Stop recording and return blob
         * Returns: Promise<Blob>
         */
        async stopRecording() {
            return new Promise((resolve, reject) => {
                if (!this.mediaRecorder || !this.isRecording) {
                    reject(new Error('Recording not active'));
                    return;
                }
                
                this.mediaRecorder.onstop = () => {
                    const mimeType = this.mediaRecorder.mimeType || 'video/webm';
                    const blob = new Blob(this.recordedChunks, { type: mimeType });
                    this.isRecording = false;
                    resolve(blob);
                };
                
                this.mediaRecorder.stop();
            });
        }
        
        /**
         * Get recorded audio as blob
         * Note: In MVP, audio is extracted server-side via ffmpeg
         * Returns: Blob
         */
        getRecordedBlob() {
            if (this.recordedChunks.length === 0) {
                throw new Error('No recorded data');
            }
            
            const mimeType = this.mediaRecorder ? this.mediaRecorder.mimeType : 'video/webm';
            return new Blob(this.recordedChunks, { type: mimeType });
        }
        
        /**
         * Stop all media tracks
         */
        stopMediaStream() {
            if (this.mediaStream) {
                this.mediaStream.getTracks().forEach(track => track.stop());
                this.mediaStream = null;
            }
        }
        
        /**
         * Check if recording is active
         */
        isRecordingActive() {
            return this.isRecording;
        }
        
        /**
         * Get video element
         */
        getVideoElement() {
            return this.videoElement;
        }
    }
    
    // Global instance
    let mediaCaptureManager = null;
    
    /**
     * Initialize media capture manager
     */
    async function initializeMediaCapture(videoElementId = 'webcamPreview') {
        try {
            mediaCaptureManager = new MediaCaptureManager(videoElementId);
            return await mediaCaptureManager.requestMediaAccess();
        } catch (error) {
            console.error('Failed to initialize media capture:', error);
            throw error;
        }
    }
    
    /**
     * Start recording
     */
    async function startRecording() {
        if (!mediaCaptureManager) {
            throw new Error('Media capture not initialized');
        }
        return await mediaCaptureManager.startRecording();
    }
    
    /**
     * Stop recording
     */
    async function stopRecording() {
        if (!mediaCaptureManager) {
            throw new Error('Media capture not initialized');
        }
        return await mediaCaptureManager.stopRecording();
    }
    
    /**
     * Get recorded blob
     */
    function getRecordedBlob() {
        if (!mediaCaptureManager) {
            throw new Error('Media capture not initialized');
        }
        return mediaCaptureManager.getRecordedBlob();
    }
    
    /**
     * Stop media stream
     */
    function stopMediaStream() {
        if (mediaCaptureManager) {
            mediaCaptureManager.stopMediaStream();
        }
    }
    
    /**
     * Check if recording is active
     */
    function isRecordingActive() {
        return mediaCaptureManager && mediaCaptureManager.isRecordingActive();
    }

    /**
     * Interview Session Manager
     * Handles question flow, timer, recording, and upload
     */
    
    class InterviewSessionManager {
        constructor(sessionId) {
            this.sessionId = sessionId;
            this.currentQuestionIndex = 0;
            this.questions = [];
            this.isRecording = false;
            this.timerInterval = null;
            this.timeRemaining = 90;
            
            // Get DOM elements
            this.questionNumberEl = document.getElementById('questionNumber');
            this.questionCategoryEl = document.getElementById('questionCategory');
            this.questionTextEl = document.getElementById('questionText');
            this.timerEl = document.getElementById('timer');
            this.timerStatusEl = document.getElementById('timerStatus');
            this.recordingIndicatorEl = document.getElementById('recordingIndicator');
            this.startRecordingBtn = document.getElementById('startRecordingBtn');
            this.stopRecordingBtn = document.getElementById('stopRecordingBtn');
            this.skipBtn = document.getElementById('skipBtn');
            this.uploadStatusEl = document.getElementById('uploadStatus');
            this.errorAlertEl = document.getElementById('errorAlert');
            this.permissionDenialEl = document.getElementById('permissionDenial');
        }
        
        /**
         * Initialize session and load first question
         */
        async initialize() {
            try {
                // Load questions from server
                const response = await fetch(`/api/v1/session/${this.sessionId}`);
                const data = await response.json();
                
                if (!response.ok) {
                    this.showError(data.error || 'Failed to load session');
                    return;
                }
                
                this.questions = data.questions;
                
                // Initialize media capture
                try {
                    await initializeMediaCapture('webcamPreview');
                    console.log('✓ Media capture initialized');
                } catch (error) {
                    this.showPermissionDenial(error.message);
                    return;
                }
                
                // Load first question
                this.loadQuestion();
                
                // Setup event listeners
                this.setupEventListeners();
            } catch (error) {
                this.showError(`Failed to initialize session: ${error.message}`);
            }
        }
        
        /**
         * Load current question
         */
        loadQuestion() {
            if (this.currentQuestionIndex >= this.questions.length) {
                this.completeInterview();
                return;
            }
            
            const question = this.questions[this.currentQuestionIndex];
            
            // Update UI
            this.questionNumberEl.textContent = `Question ${this.currentQuestionIndex + 1} / ${this.questions.length}`;
            this.questionCategoryEl.textContent = question.category.charAt(0).toUpperCase() + question.category.slice(1);
            this.questionTextEl.textContent = question.text;
            
            // Reset controls
            this.timeRemaining = 90;
            this.updateTimer();
            this.isRecording = false;
            this.recordingIndicatorEl.classList.add('hidden');
            this.startRecordingBtn.classList.remove('hidden');
            this.stopRecordingBtn.classList.add('hidden');
            this.uploadStatusEl.classList.add('hidden');
            this.timerStatusEl.textContent = 'Ready';
        }
        
        /**
         * Start recording current question
         */
        async startRecording() {
            try {
                await startRecording();
                this.isRecording = true;
                
                // Update UI
                this.startRecordingBtn.classList.add('hidden');
                this.stopRecordingBtn.classList.remove('hidden');
                this.recordingIndicatorEl.classList.remove('hidden');
                this.timerStatusEl.textContent = 'Recording...';
                
                // Start timer
                this.startTimer();
            } catch (error) {
                this.showError(`Failed to start recording: ${error.message}`);
            }
        }
        
        /**
         * Stop recording current question
         */
        async stopRecording() {
            try {
                // Stop timer
                if (this.timerInterval) {
                    clearInterval(this.timerInterval);
                }
                
                const blob = await window.stopRecording();
                this.isRecording = false;
                
                // Update UI
                this.stopRecordingBtn.classList.add('hidden');
                this.recordingIndicatorEl.classList.add('hidden');
                this.timerStatusEl.textContent = 'Uploading...';
                this.uploadStatusEl.classList.remove('hidden');
                
                // Upload response
                await this.uploadResponse(blob);
                
                // Move to next question
                this.currentQuestionIndex++;
                this.loadQuestion();
            } catch (error) {
                this.showError(`Failed to stop recording: ${error.message}`);
            }
        }
        
        /**
         * Upload response to server
         */
        async uploadResponse(blob) {
            const question = this.questions[this.currentQuestionIndex];
            const formData = new FormData();
            formData.append('session_id', this.sessionId);
            formData.append('question_id', question.id || this.currentQuestionIndex + 1);
            formData.append('video', blob, `q${this.currentQuestionIndex + 1}.webm`);
            
            try {
                const response = await fetch('/api/v1/session/upload-response', {
                    method: 'POST',
                    body: formData
                });
                
                const data = await response.json();
                
                if (!response.ok) {
                    throw new Error(data.error || 'Upload failed');
                }
                
                console.log(`✓ Question ${this.currentQuestionIndex + 1} uploaded`);
            } catch (error) {
                throw new Error(`Upload failed: ${error.message}`);
            }
        }
        
        /**
         * Start countdown timer
         */
        startTimer() {
            if (this.timerInterval) {
                clearInterval(this.timerInterval);
            }
            
            this.timerInterval = setInterval(() => {
                this.timeRemaining--;
                this.updateTimer();
                
                if (this.timeRemaining <= 0) {
                    clearInterval(this.timerInterval);
                    this.showError('Time\'s up! Stopping recording...');
                    this.stopRecording();
                }
            }, 1000);
        }
        
        /**
         * Update timer display
         */
        updateTimer() {
            const minutes = Math.floor(this.timeRemaining / 60);
            const seconds = this.timeRemaining % 60;
            this.timerEl.textContent = `${String(minutes).padStart(2, '0')}:${String(seconds).padStart(2, '0')}`;
            
            // Change color if running low on time
            if (this.timeRemaining <= 10) {
                this.timerEl.style.color = '#e74c3c';
            } else {
                this.timerEl.style.color = '#2c3e50';
            }

    import os
    import shutil
    import subprocess
    from pathlib import Path
    from datetime import datetime
    
    class MediaHandlingError(Exception):
        """Media handling error"""
        pass
    
    class MediaHandler:
        """Handle media file storage and processing"""
        
        def __init__(self, base_recordings_dir: str = 'recordings'):
            self.base_recordings_dir = base_recordings_dir
            os.makedirs(base_recordings_dir, exist_ok=True)
        
        def get_session_dir(self, session_id: int) -> str:
            """Get or create session directory"""
            session_dir = os.path.join(self.base_recordings_dir, f'session_{session_id}')
            os.makedirs(session_dir, exist_ok=True)
            return session_dir
        
        def save_media(self, blob: bytes, session_id: int, question_number: int) -> dict:
            """
            Save uploaded WebM blob to disk.
            
            Args:
                blob: WebM video blob (bytes)
                session_id: Session ID
                question_number: Question number (1-indexed)
                
            Returns:
                Dict with paths: {'webm_path': str, 'wav_path': str}
            """
            try:
                session_dir = self.get_session_dir(session_id)
                
                # Save WebM file
                webm_filename = f'q{question_number}.webm'
                webm_path = os.path.join(session_dir, webm_filename)
                
                with open(webm_path, 'wb') as f:
                    f.write(blob)
                
                # Extract audio to WAV
                wav_filename = f'q{question_number}.wav'
                wav_path = os.path.join(session_dir, wav_filename)
                
                self.extract_audio(webm_path, wav_path)
                
                return {
                    'webm_path': webm_path,
                    'wav_path': wav_path,
                    'webm_filename': webm_filename,
                    'wav_filename': wav_filename
                }
            
            except Exception as e:
                raise MediaHandlingError(f"Failed to save media: {str(e)}")
        
        def extract_audio(self, video_path: str, output_audio_path: str, format: str = 'wav') -> str:
            """
            Extract audio from video using ffmpeg.
            
            Creates a WAV file from the audio track of a WebM video.
            
            Args:
                video_path: Path to WebM video file
                output_audio_path: Path to output audio file (WAV)
                format: Output format (default: 'wav')
                
            Returns:
                Path to audio file
                
            Raises:
                MediaHandlingError: If ffmpeg not found or extraction fails
            """
            try:
                # Check if ffmpeg is available
                shutil.which('ffmpeg')
                if not shutil.which('ffmpeg'):
                    raise MediaHandlingError("ffmpeg not found. Install with: apt-get install ffmpeg (Linux) or brew install ffmpeg (Mac)")
                
                # Run ffmpeg command
                cmd = [
                    'ffmpeg',
                    '-i', video_path,
                    '-q:a', '9',  # Audio quality (0-9, higher = better; 9 = highest)
                    '-acodec', 'libmp3lame',  # Use MP3 codec
                    '-y',  # Overwrite output file
                    output_audio_path
                ]
                
                # Run with suppressed output
                result = subprocess.run(
                    cmd,
                    capture_output=True,
                    timeout=60
                )
                
                if result.returncode != 0:
                    error_msg = result.stderr.decode('utf-8', errors='ignore')
                    raise MediaHandlingError(f"ffmpeg extraction failed: {error_msg}")
                
                return output_audio_path
            
            except subprocess.TimeoutExpired:
                raise MediaHandlingError("Audio extraction timed out (60s limit)")
            except Exception as e:
                raise MediaHandlingError(f"Failed to extract audio: {str(e)}")
        
        def get_media_file_path(self, session_id: int, question_number: int, media_type: str = 'webm') -> str:
            """
            Get path to a media file.
            
            Args:
                session_id: Session ID
                question_number: Question number
                media_type: 'webm' or 'wav'
                
            Returns:
                Path to media file
            """
            session_dir = self.get_session_dir(session_id)
            ext = 'webm' if media_type == 'webm' else 'wav'
            return os.path.join(session_dir, f'q{question_number}.{ext}')
        
        def list_session_media(self, session_id: int) -> dict:
            """
            List all media files for a session.
            
            Returns:
                Dict with sorted lists of WebM and WAV files
            """
            session_dir = self.get_session_dir(session_id)
            
            files = os.listdir(session_dir)
            webm_files = sorted([f for f in files if f.endswith('.webm')])
            wav_files = sorted([f for f in files if f.endswith('.wav')])
            
            return {
                'webm_count': len(webm_files),
                'wav_count': len(wav_files),
                'webm_files': webm_files,
                'wav_files': wav_files
            }
        
        def delete_session_media(self, session_id: int) -> bool:
            """
            Delete all media for a session (cleanup).
            
            Args:
                session_id: Session ID
                
            Returns:
                True if successful
            """
            try:
                session_dir = self.get_session_dir(session_id)
                if os.path.exists(session_dir):
                    shutil.rmtree(session_dir)
                return True
            except Exception as e:
                raise MediaHandlingError(f"Failed to delete session media: {str(e)}")
    
    # Global instance
    media_handler = MediaHandler()
    
    def save_media_for_response(blob: bytes, session_id: int, question_number: int) -> dict:
        """Convenience function"""
        return media_handler.save_media(blob, session_id, question_number)
    
    def get_media_path(session_id: int, question_number: int, media_type: str) -> str:
        """Convenience function"""
        return media_handler.get_media_file_path(session_id, question_number, media_type)
